# 🐢 Projeto LOGO: A Tartaruga Atômica 🚀

Bem-vindo ao **Mini LOGO Turtle**, o projeto que resgatou uma das maiores lendas da computação dos anos 80/90 e deu a ela superpoderes modernos! Esqueça comandos chatos de terminal preto e branco; aqui a nossa tartaruga é movida a cliques, comandos de voz (mentira, teclado mesmo) e um rastro neon estilo *Tron*!

Este projeto recria a clássica linguagem de programação **LOGO**, onde você controla uma tartaruga desenhista em uma tela digital, ideal para brincar, criar formas geométricas psicodélicas ou apenas ver uma tartaruguinha girando no próprio eixo.

---

## 🎮 Funcionalidades Iradas

* **Controle Híbrido:** Use o terminal para digitar comandos clássicos ou use o painel lateral com botões coloridos (perfeito para jogar no celular ou tablet!).
* **Teletransporte Quântico:** Clique em qualquer lugar da tela preta e a tartaruga voa para lá sem deixar rastro, pronta para um novo desenho.
* **Caneta Inteligente:** Ative ou desative o rastro com um clique. Quando a caneta sobe, o casco dela fica cinza (modo furtivo)!
* **Modo Rave (Arco-Íris):** Desenhe linhas mágicas que mudam de cor dinamicamente a cada passo dado.

---

## 🛠️ Comandos Clássicos do Terminal

Clique na caixa de texto inferior e digite (sempre com espaço entre o comando e o número):

* `pf 100` -> **P**ara **F**rente 100 passos.
* `pd 90`  -> **P**ara **D**ireita 90 graus.
* `pe 45`  -> **P**ara **E**squerda 45 graus.
* `sc`      -> **S**olta **C**aneta (anda sem desenhar).
* `pc`      -> **P**ega **C**aneta (volta a desenhar).
* `limpe`   -> Apaga todas as suas obras de arte e recomeça do centro.

> **Desafio Supremo:** Digite `pf 100 pd 90 pf 100 pd 90 pf 100 pd 90 pf 100` e veja um quadrado perfeito surgir num piscar de olhos!

## 💻 Como Rodar Esse Projeto no seu Computador

Se você baixou os arquivos gerados no Google Colab, para rodar na sua máquina é mais fácil do que andar para frente:

1. Baixe os três arquivos: `index.html`, `style.css` e `script.js`.
2. Coloque os três **obrigatoriamente na mesma pasta** (se separar eles choram e quebram).
3. Dê um duplo clique no `index.html`.
4. Pronto! Seu navegador vai abrir o jogo instantaneamente.

## 🌎 Como Foi Desenvolvido?

Este projeto nasceu de uma mente brilhante dentro das linhas de código do **Google Colab**, utilizando:
* **HTML5** para a estrutura das telas.
* **CSS3** para deixar o visual escuro (cyberpunk) e botões anatômicos.
* **JavaScript Puro (Vanilla)** no controle da física de rotação e renderização geométrica via Canvas.
